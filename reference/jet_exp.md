# The Exponential of a Jet

\\e^a\\, whose four derivatives are all \\e^a\\.

## Usage

``` r
jet_exp(a, lay = a$lay)
```

## Arguments

- a:

  A jet.

- lay:

  A layout from
  [`jet_layout`](https://statmodels7.github.io/numericals7/reference/jet_layout.md);
  taken from the jet itself unless given.

## Value

A jet.
