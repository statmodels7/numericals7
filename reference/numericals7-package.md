# numericals7: Numerical Kernels for Statistical Modeling

The numerical layer of a statistical modeling toolkit, written once and
consumed by the packages above it. The combinatorial enumerations a
higher-order chain rule rests on – index tuples, set partitions, weak
compositions – live beside them, in one copy.
