# The Logarithm of a Jet

\\\log a\\, with derivatives \\(-1)^{k-1}(k-1)!/a^k\\.

## Usage

``` r
jet_log(a, lay = a$lay)
```

## Arguments

- a:

  A jet.

- lay:

  A layout from
  [`jet_layout`](https://statmodels7.github.io/numericals7/reference/jet_layout.md);
  taken from the jet itself unless given.

## Value

A jet.
