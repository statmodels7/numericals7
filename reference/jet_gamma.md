# The Gamma Function of a Jet

\\\Gamma(a)\\, formed as \\\exp\log\Gamma(a)\\ so that the derivatives
come from the polygamma functions rather than from a second table.

## Usage

``` r
jet_gamma(a, lay = a$lay)
```

## Arguments

- a:

  A jet.

- lay:

  A layout from
  [`jet_layout`](https://statmodels7.github.io/numericals7/reference/jet_layout.md);
  taken from the jet itself unless given.

## Value

A jet.
