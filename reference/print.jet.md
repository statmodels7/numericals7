# Print a Jet

Shows the value and how many variables the derivatives are taken in,
rather than the whole list of components, which is thirty-five numbers
even in two variables.

## Usage

``` r
# S3 method for class 'jet'
print(x, ...)
```

## Arguments

- x:

  A jet.

- ...:

  Unused.

## Value

`x`, invisibly.
