# The Reciprocal of a Jet

\\1/a\\, the common case of
[`jet_pow`](https://statmodels7.github.io/numericals7/reference/jet_pow.md).

## Usage

``` r
jet_inv(a, lay = a$lay)
```

## Arguments

- a:

  A jet.

- lay:

  A layout from
  [`jet_layout`](https://statmodels7.github.io/numericals7/reference/jet_layout.md);
  taken from the jet itself unless given.

## Value

A jet.
