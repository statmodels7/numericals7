# A Power of a Jet

\\a^p\\ for any real exponent, which covers the square root, the
reciprocal and the square without a routine for each.

## Usage

``` r
jet_pow(a, p, lay = a$lay)
```

## Arguments

- a:

  A jet.

- p:

  The exponent.

- lay:

  A layout from
  [`jet_layout`](https://statmodels7.github.io/numericals7/reference/jet_layout.md);
  taken from the jet itself unless given.

## Value

A jet.
