# The Log-Gamma of a Jet

\\\log\Gamma(a)\\, whose derivatives are the polygamma functions.

## Usage

``` r
jet_lgamma(a, lay = a$lay)
```

## Arguments

- a:

  A jet.

- lay:

  A layout from
  [`jet_layout`](https://statmodels7.github.io/numericals7/reference/jet_layout.md);
  taken from the jet itself unless given.

## Value

A jet.
