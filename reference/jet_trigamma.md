# The Trigamma of a Jet

\\\psi'(a)\\, with the polygamma functions above it.

## Usage

``` r
jet_trigamma(a, lay = a$lay)
```

## Arguments

- a:

  A jet.

- lay:

  A layout from
  [`jet_layout`](https://statmodels7.github.io/numericals7/reference/jet_layout.md);
  taken from the jet itself unless given.

## Value

A jet.
